# ⚽ Vascão Season 3

Plataforma web desenvolvida para organizar e acompanhar as competições da comunidade **DreamTeam**.

O sistema centraliza informações sobre campeonatos, clubes, jogadores, partidas, classificações, estatísticas, notícias e histórico das competições em uma única aplicação.

🌐 **Aplicação em produção:**  
https://vascaoseason3-ironhaven.up.railway.app/

---

## 🚀 Funcionalidades

- Gerenciamento de competições e temporadas
- Cadastro e gerenciamento de clubes
- Cadastro de jogadores e participantes
- Registro de partidas e resultados
- Classificação automática dos campeonatos
- Estatísticas das equipes e jogadores
- Sistema de notícias
- Histórico de títulos
- Gerenciamento de confrontos
- Área administrativa
- Suporte a diferentes formatos de competição
- Deploy separado entre homologação e produção

---

## 🏆 Competições

A plataforma suporta diferentes formatos de competição, incluindo:

- Campeonato por pontos corridos
- Copa com sistema mata-mata
- Supercopas
- Torneios amistosos
- Competições internacionais
- Eventos especiais da temporada
